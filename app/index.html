阅读项目说明
FIRST START

先选择永久数据文件夹

English Learning Path 不把学习档案存进浏览器缓存。请选择一个长期保留的本地文件夹，题目、作文和练习记录都会直接写入其中。

新用户选择或新建空文件夹程序会建立数据文件与虾滑、ZYZ 两个资源目录。
已有数据选择以前绑定的文件夹检测到 EnglishLearnPath-data.json 后自动恢复。
完成选择前不会显示路径，也不会把练习记录写入浏览器缓存。
