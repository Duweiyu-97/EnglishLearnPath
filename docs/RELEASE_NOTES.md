# v0.4.1 · 自动保存与复盘优先版

本版继续只专注写作与口语，并修正实际使用流程：

- 写作和口语取消单独保存按钮；输入、题图、录音、转写与后续校对会自动写入本地数据文件，AI 批改前也会强制完成写盘。
- 口语只保留“一次录音 → 结束后本地 Whisper 转写”的单一路径，不再提供浏览器实时转写选项。
- 自由写作的“不计时”改为从 `00:00` 开始正计时；Task 1 仍为 20 分钟，Task 2 为 40 分钟。
- 学习计划限制每天最多 1 篇新写作、2 次新口语，明确拆分写作精改、重写、口语回听重说、常用语料记忆与错题/单词复盘；AI 计划会保证每个新输出后都有复盘闭环。
- 写作批改只把无争议的语法、拼写和机械错误标红；自然度、简洁度、词汇提升、衔接和论证建议单独放入“可选优化建议”，不会把正确句子判错。
- 调整题图、转写、动作区与说明文字的间距，并精简 DeepSeek 预设名称。

仍包含独立 Markdown 批改页、原文修改标注与双向定位、错题/单词本、本地加密保存 API 配置，以及完整离线 Whisper 组件。听力、阅读题库不内置或适配。

下载 **EnglishLearnPath-Windows-x64-Full-*.zip**，全部解压到有写入权限的普通文件夹，双击“启动学习中心.exe”。不要只下载 GitHub 的 Source code ZIP。Windows 10/11 x64；使用系统自带 Edge 或现代 Chrome；无需安装 Python、FFmpeg、VC 运行库或另外下载语音模型。

整包包含学习中心、CPU 版 whisper.cpp、Whisper small.en 英语模型。默认本地转写：录音结束后离线识别，音频不上传，不需要语音 API Key。深度批改仍按需使用用户自己的 DeepSeek 等文字接口。速度取决于电脑，建议至少 4 GB 内存；单段支持 8 分钟以内。请回听核对，模型可能产生误识别。
