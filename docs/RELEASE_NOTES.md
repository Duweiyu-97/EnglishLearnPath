# v0.7.0 · 错句复习与单词记忆

## 本次更新

- 写作与口语批改均支持逐条选择“加入错题本”：只收录能对应原文的错句、参考修改和原因，自动避免重复，不再整篇导入。
- 错句可先自行纠错，再查看参考答案，按“再练一次 / 有点难 / 掌握了”安排后续复习；也可随时单独练习某一句。复习进度保存在绑定的数据目录中。
- 单词本新增先回忆、再揭晓释义与例句的记忆练习，并根据记忆表现安排复习。
- 精简批改对照行、错题卡片与复习工具栏。错题本左侧表单完整显示，右侧列表独立滚动；窄屏自动调整布局。错题图片支持点击放大。
- 写作暂停计时后禁止编辑正文，继续计时后恢复输入，保留已有草稿。
- 加强 AI 返回内容的结构校验与过滤，隐藏无法识别的内容，修复空批改区、异常通用表达及口语语料混入作文的问题。
- 改进原文标注匹配，避免把单词内部片段或纯破折号风格差异误标为语法错误；学习计划遇到格式或可重试的服务异常时自动重试一次，生成失败不替换旧计划。

## 升级与使用提示

- 下载 `EnglishLearnPath-Windows-x64-Full-v0.7.0.zip`，完整解压后双击 `启动学习中心.exe`。完整包继续内置本地离线 Whisper 转写组件；云端 AI 批改仍需自行配置服务。
- 升级前建议导出学习备份，并用 `结束学习中心.exe` 结束旧版后台服务。将新版解压到新目录，启动后选择原先的数据文件夹即可恢复学习记录；不要删除自己的数据文件夹。
- 新目录中的 API 配置需重新填写。不要将旧副本的 `runtime-data` 或个人学习数据上传、打包分享。
- 旧错题记录完整保留，不会自动拆分为错句；需要从批改页逐条收录后，才参与新的错句纠错复习。
- 参考修改来自已保存的 AI 批改，复习表现由使用者自评，不会额外调用 AI。模型返回内容仍可能变化，结构过滤不能保证所有语言判断正确。

## v0.6.0 · 统一批改体验与可记忆语料库

## 本次更新

- 写作与口语首页改为轻量概览：默认展示今日计划、推荐记忆语料和练习记录，只有点击“新建练习”才进入完整答题界面；首页仅汇总写作与口语完成度，详细计划分别留在对应模块。
- Task 1、Task 2 与口语 Part 1、Part 2、Part 3 的批改页统一为同一套板块顺序、卡片尺寸和视觉样式，并补齐原题、评分、总体评价、原文标注、确定错误、优化建议、范文和可复用语料。
- 批改提示词内置 IELTS 官方公开评分维度和常用分档校准，明确传入具体 Task 或 Part、实际词数或录音时长；Task 1 检查 150 词，Task 2 检查 250 词，Part 2 检查 1–2 分钟长回答。口语发音仍不会仅凭转写臆测评分。
- 题目图片改为完整缩略预览，带图片的 Task 1 使用左右布局；点击放大镜可全屏查看原图。
- 个人语料库按口语与写作严格分流。口语相似主题自动合并，只处理尚未汇总的新记录；写作按教育、科技、犯罪与法律、商业与经济等领域以及通用表达归类，每日只展示少量重点。
- 口语与写作表达统一使用“英文在上、中文释义在下”的双语样式。旧英文话题标签会规范为中文，缺少的释义可在后续更新中补齐。
- 语料卡支持删除；删除后会同步写入本地数据文件，并只重置对应原始练习的处理标记。练习、计划、语料、删除状态与 AI 处理记录均以绑定的数据文件为准，不依赖浏览器缓存。

## 使用提示

- 下载 `EnglishLearnPath-Windows-x64-Full-v0.6.0.zip` 后完整解压，再双击 `启动学习中心.exe`。
- 升级不会删除此前绑定的数据目录。建议先用旧版或新版包中的 `结束学习中心.exe` 结束后台服务，再解压并启动新版。
- 新评分标准只用于之后生成的批改；已经保存的旧报告不会自动重新请求 AI。

## v0.5.0 · 专注答题、分 Part 口语与个人语料库

## 本次新增

- 写作和口语加入专注答题模式：可折叠全局导航，隐藏练习时不需要的页面区域；桌面宽屏同时显示题目、计时与答题区，不再需要上下反复滚动。
- IELTS 口语按 Part 区分操作和批改逻辑。完整题目、明确的 Part 名称和对应答题要求会一起发送给 AI；Part 2 先进行 1 分钟不录音准备，再自动开始最多 2 分钟录音回答。
- 写作、口语报告统一改成评分优先：总分与小分置顶，其后依次为总体评价、原文标注、确定错误、可选优化、目标水平范文和最终值得记忆的语料。口语提供基于转写的暂定总分与 FC、LR、GRA 小分，并明确发音无法仅凭文字判断。
- 新增“个人语料库”。由使用者手动按需更新，阶段性汇总本机现有与新增答题记录；口语整理个人真实素材、可迁移话题、表达和答题骨架，写作整理领域词组、搭配与常用句式。不会在每次答题后自动调用 AI，结果持久保存在本地。
- 不同 OpenAI 兼容服务统一使用功能级输出契约。学习计划和个人语料库采用经过验证的 JSON，批改报告采用固定章节顺序的 Markdown；本地代理会拒绝缺少必需结构的返回，防止错误格式直接填入网页。
- 首页移除重复的写作、口语大入口，收紧无效留白；口语左右面板、控件间距与答题区域重新布局。
- 完整包继续包含 `结束学习中心.exe`。升级或删除旧版本前双击即可释放被后台启动器占用的目录，不结束浏览器，也不删除学习数据或 API 配置。

## 使用提示

- 下载 `EnglishLearnPath-Windows-x64-Full-v0.5.0.zip` 后必须完整解压，再双击 `启动学习中心.exe`。
- 个人语料库只在点击“更新个人语料库”时调用已配置的文字 AI，只发送题目、回答和已有反馈文字；录音和题目图片不参与汇总。
- 口语录音仍由包内 whisper.cpp + Whisper small.en 在本机离线转写，原始音频不会发送给文字 AI。请回听核对转写结果。

## v0.4.3 · 后台服务结束工具

### 本次新增

- 完整包根目录新增 `结束学习中心.exe`。关闭浏览器后如果启动器仍占用旧文件夹，双击该工具即可结束所有仍在运行的 English Learning Path 本地服务，然后删除或替换旧版本目录。
- 结束工具只匹配产品启动器 `启动学习中心.exe`，不会结束浏览器，也不会删除学习记录、数据目录或 API 配置。
- 启动器版本信息改为随 Release 标签写入，不再固定显示旧版本号。

## v0.4.2 · DeepSeek 题图识别

- 写作批改现在会把题目图片作为真实多模态输入发送给已配置的兼容 API，不再要求模型根据文字猜图。
- 使用 DeepSeek 官方地址时，纯文字反馈仍使用已配置的 `deepseek-v4-flash`；一旦本题含图片，该次请求自动切换到 `deepseek-v4-flash-vision-exp`，沿用同一枚 API Key。
- 支持随题保存的 PNG、JPEG、GIF 与 WebP 图片，最多 6 张；图片与题目、正文在一次请求中完成分析。
- 录音仍坚持本机 whisper.cpp 离线转写。DeepSeek 当前公开视觉模型不接受音频，应用不会把原始口语录音发送给 DeepSeek。

## v0.4.1 基础改进

本版继续只专注写作与口语，并修正实际使用流程：

- 写作和口语取消单独保存按钮；输入、题图、录音、转写与后续校对会自动写入本地数据文件，AI 批改前也会强制完成写盘。
- 口语只保留“一次录音 → 结束后本地 Whisper 转写”的单一路径，不再提供浏览器实时转写选项。
- 自由写作的“不计时”改为从 `00:00` 开始正计时；Task 1 仍为 20 分钟，Task 2 为 40 分钟。
- 学习计划限制每天最多 1 篇新写作、2 次新口语，明确拆分写作精改、重写、口语回听重说、常用语料记忆与错题/单词复盘；AI 计划会保证每个新输出后都有复盘闭环。
- 写作批改只把无争议的语法、拼写和机械错误标红；自然度、简洁度、词汇提升、衔接和论证建议单独放入“可选优化建议”，不会把正确句子判错。
- 调整题图、转写、动作区与说明文字的间距，并精简 DeepSeek 预设名称。

仍包含独立 Markdown 批改页、原文修改标注与双向定位、错题/单词本、本地加密保存 API 配置，以及完整离线 Whisper 组件。听力、阅读题库不内置或适配。

下载 **EnglishLearnPath-Windows-x64-Full-*.zip**，全部解压到有写入权限的普通文件夹，双击“启动学习中心.exe”。不要只下载 GitHub 的 Source code ZIP。Windows 10/11 x64；使用系统自带 Edge 或现代 Chrome；无需安装 Python、FFmpeg、VC 运行库或另外下载语音模型。

整包包含学习中心、CPU 版 whisper.cpp、Whisper small.en 英语模型。默认本地转写：录音结束后离线识别，音频不上传，不需要语音 API Key。深度批改按需使用用户自己的 DeepSeek 等接口，只有写作题图会随批改请求发送给视觉模型。速度取决于电脑，建议至少 4 GB 内存；单段支持 8 分钟以内。请回听核对，模型可能产生误识别。
