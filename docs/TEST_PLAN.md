# 原版功能回归清单

范围以 v0.7.4 为基准：写作、口语、学习计划、个人语料、错题与单词、本地存储、AI 设置及双平台启动器。修复不得增加模块、资料库或改变原界面。

验收顺序固定为：原版功能回归 → 复现并修复报告故障 → Windows/macOS 自测 → 在本仓库维护测试规范及证据。

## 本次故障：返回日期不匹配

原实现把阶段内序号 weekday 同时描述成自然星期，并要求返回数组位置和日期逐字一致。周中开始、拆批或模型返回自然星期/日期格式变体时，合法日期也可能失败。复现入口为 plan-date-alignment 和 plan-date-browser；修复后由本地日历给出 requestedDays，每项明确 date、dayIndex 和 calendarWeekday，优先按日期对齐。重复、漏日、越界或序号冲突继续拒绝；格式重试带具体反馈，失败保留原计划。

计划时间由程序复核，明确的0次任务不被默认扩张；写作保存失败不能误标完成，编辑已完成稿保留原完成时间。原版界面文件与功能入口保持不变。

GitHub网页可直接编辑本清单；提交后由 Actions 执行固定回归。运行结果保存在 Actions，人工验收在 Issue 中引用用例与运行链接。

开发者可选执行：Node 22、Go 1.22+；npm ci，npx playwright install chromium，然后设置 ELP_BROWSER_CHANNEL=bundled 并运行 npm test。普通使用者无需在本机维护测试环境。
