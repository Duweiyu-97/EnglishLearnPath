材料导入格式

导入文件采用 UTF-8 编码的 JSON。一个文件可以是单个对象，也可以是由多个对象组成的数组。项目中的 examples 文件夹提供了完全原创的示例。

请只导入你有权使用的内容。音频不会写进 JSON，进入听力练习后再从本机选择。

听力 JSON

{
  "title": "材料标题",
  "description": "可选说明",
  "source": "来源或许可说明",
  "questions": [
    {
      "prompt": "Question 1 ...",
      "answer": "参考答案",
      "explanation": "可选解析"
    }
  ]
}

阅读 JSON

{
  "title": "Passage title",
  "description": "可选说明",
  "source": "来源或许可说明",
  "paragraphs": [
    {
      "label": "A",
      "text": "English paragraph...",
      "translation": "中文翻译……",
      "summary": "本段大意……"
    }
  ],
  "questions": [
    {
      "prompt": "Question 1 ...",
      "answer": "参考答案",
      "explanation": "定位方法与逐题解析"
    }
  ]
}

注意事项

  • 程序会为材料生成本机 ID，无需自行填写。
  • 阅读文章的翻译、段意、答案与解析会直接随文章展开。
  • HTML 内容不会被执行，所有导入文字都会作为普通文本显示。
  • 先在设置页导出备份，再清除浏览器数据或更换浏览器。
