## 固定目录

启动学习中心后，进入“AI 与数据设置”，可以看到两个永久固定目录：

```text
你绑定的数据文件夹/
└─ resources/
   ├─ Listening-Xiahua/   # 虾滑听力
   └─ Reading-ZYZ/        # ZYZ 阅读
```

点击听力页的“打开虾滑目录”或阅读页的“打开 ZYZ 目录”，可直接在 Windows 资源管理器中定位。

也可以直接点击对应页面的“导入或更新题库”，一次选择一个或多个 ZIP。程序会自动复制、解压和刷新列表；相同内容的重复包会跳过，同名但内容不同的新版会保留为带更新时间的副本，不会覆盖旧文件。

## 压缩包怎么放

虾滑听力常见形式：

```text
Listening-Xiahua/
├─ IELTS Listening 虾滑普通版（至某日期 共若干篇）.zip
├─ 120. P2 某篇标题.zip
└─ 124. P3 某篇标题.zip
```

集合包和后续单篇增量包可以同时保留。常见单篇内部包含：

```text
编号. P1-P4 标题/
├─ 同名练习页面.html
├─ audio.mp3
└─ 可选 PDF
```

ZYZ 阅读常见形式：

```text
Reading-ZYZ/
├─ [PDF] ZYZ 七月合集.zip
├─ [PDF] ZYZ 八月合集.zip
└─ 以后取得的月度资料.zip
```

月度包通常按高频、非高频或背景知识等子目录组织 PDF。程序会递归识别，不要求你改名或移动 PDF。

## 扫描规则

1. ZIP 可以直接放入固定目录，无需手工解压；
2. 点击“重新扫描”，程序会在同一资源目录的隐藏子目录 `.EnglishLearnPath-extracted` 中安全解压；
3. 已经解压好的文件夹也可以直接放入；
4. 听力模块识别 HTML 练习页，阅读模块识别 PDF 或 HTML；
5. 点击材料后，程序使用本机默认浏览器或 PDF 阅读器打开；
6. 新增月度包或增量包后，再点击一次扫描即可；
7. 当前不直接解压 RAR/7z，如拿到的是这两种格式，请先自行解压到对应固定目录。

程序会阻止压缩包路径越界、符号链接和异常大的解压内容。它不会把你的资源上传到 GitHub、云端或 AI 服务。
