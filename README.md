# English Learning Path · 英语学习路径

一个本地优先、内容由使用者掌控的开源英语学习中心。它提供听、读、写、说四项练习框架，但**不附带商业题库、课程资料、受版权保护的录音或私人模板**。

## 普通使用者：下载即用

1. 打开右侧 **Releases**；
2. 下载最新的 `EnglishLearnPath-Windows-x64-版本号.zip`；
3. 完整解压 ZIP；
4. 双击 `启动学习中心.exe`，程序会在默认浏览器中打开。

不需要安装 Node.js、Python、数据库或其他依赖。请不要只下载绿色的 “Code → Download ZIP”，那是开发者源码，不含已经编译好的启动器。

第一次启动时，页面会先要求你**选择或创建一个永久数据文件夹**。完成选择后才会建立并显示主数据文件、虾滑听力目录和 ZYZ 阅读目录；程序不会预先显示开发者电脑的路径，也不会退回浏览器缓存。如果选择的是以前用过且包含 `EnglishLearnPath-data.json` 的文件夹，历史记录会自动载入。

> 当前便携包优先支持 Windows 10/11 x64。首次运行时，Windows 可能显示来自未知发布者的安全提示，因为开源版本暂未购买代码签名证书。

## 功能

- **听力**：导入自己的 JSON 题目结构，在练习时选择本机音频，逐题核对答案与解析；不内置题库和录音。
- **阅读**：导入文章、翻译、段落大意、答案及解析；选中文章后所有解析直接随文章展示。
- **写作**：自定义题目、计时、字数统计、本地历史与可选 AI 反馈；不内置私人模板或课程讲义。
- **口语**：自定义话题、浏览器本地录音、回听、文字稿记录与可选 AI 文本反馈；录音不会自动上传。
- **本地资源接入**：虾滑听力和 ZYZ 阅读均有固定目录；ZIP 放入后自动安全解压、扫描并显示。
- **永久数据**：题目、作文、练习记录和设置写入绑定文件夹中的 `EnglishLearnPath-data.json`，不使用浏览器缓存作为数据源。
- **AI**：基础功能完全离线；高级反馈支持使用者自己的 OpenAI 兼容 API 或本地模型。

## AI 配置

进入“AI 与数据设置”，填写接口地址、API Key 和模型名。连接测试成功后，AI 按钮才会启用。

- Key 只保存在启动器的进程内存中，退出后自动清除。
- Key 不写入本地存储、备份文件或仓库。
- 本地模型需要使用者自行安装和启动，本项目只保留兼容接口。
- 连接测试会发送一条极短请求，云端 API 可能收取极少量费用。

详见 [AI 配置说明](docs/AI_CONFIGURATION.md)。

## 学习材料从哪里来

可以使用自己创作/录制的材料、官方公开样题、明确采用开放许可的材料，以及自己合法取得并只在个人范围内使用的材料。本项目不提供商业题库下载、镜像或绕过付费和传播限制的方法。

项目预留了两个固定目录：

```text
你绑定的数据文件夹/
└─ resources/
   ├─ Listening-Xiahua/   # 放虾滑听力 ZIP 或解压目录
   └─ Reading-ZYZ/        # 放 ZYZ 阅读 ZIP 或解压目录
```

ZIP 无需手工解压。放入后回到对应页面点击“重新扫描”，即可在学习中心看到材料。集合包、月度包和后续增量包可以同时存在。

使用过程中可以随时点击“导入或更新虾滑题库”或“导入或更新 ZYZ 题库”，一次选择多个新 ZIP；也可以手动把更新包放进固定目录后点击“重新扫描”。重复包会跳过，同名新版会另存，不会自动删除旧资料。

## 隐私说明

学习记录永久写入你绑定的本地文件夹。程序每次覆盖主数据前保留滚动备份，并按天保留一份备份；清除浏览器缓存或更换浏览器不会删除记录。换电脑时复制整个数据文件夹，再在新电脑上重新绑定即可。

录音默认只在当前页面会话中保留，需要长期保存时请主动下载到数据文件夹或其他个人目录。

当你主动使用 AI 反馈时，作文或口语文字稿会发送给你配置的服务商；听阅材料和音频不会被项目自动发送。请自行阅读相关服务商的隐私政策。

## 开发与构建

前端位于 `app/`，使用原生 HTML/CSS/JavaScript，无 npm 运行时依赖。`launcher/` 是仅使用 Go 标准库的本地启动器、本地文件存储、资源扫描器和 AI 代理。

开发者需要 Go 1.22+：

```powershell
go run ./launcher
```

构建 Windows 便携包：

```powershell
./build-portable.ps1 -Version dev
```

推送 `v*` 标签后，GitHub Actions 会自动生成 Release ZIP。普通使用者无需这些开发依赖。
