# EnglishLearnPath · 英语学习路径

一个本地优先、内容由使用者掌控的开源英语学习中心。它提供听、读、写、说四项练习框架，但**不附带商业题库、课程资料、受版权保护的录音或私人模板**。

## 普通使用者：下载即用

1. 打开右侧 **Releases**；
2. 下载最新的 `EnglishLearnPath-Windows-x64-版本号.zip`；
3. 完整解压 ZIP；
4. 双击 `启动学习中心.exe`，程序会在默认浏览器中打开。

不需要安装 Node.js、Python、数据库或其他依赖。请不要只下载绿色的 “Code → Download ZIP”，那是开发者源码，不含已经编译好的启动器。

> 当前便携包优先支持 Windows 10/11 x64。首次运行时，Windows 可能显示来自未知发布者的安全提示，因为开源版本暂未购买代码签名证书。

## 功能

- **听力**：导入自己的 JSON 题目结构，在练习时选择本机音频，逐题核对答案与解析；不内置题库和录音。
- **阅读**：导入文章、翻译、段落大意、答案及解析；选中文章后所有解析直接随文章展示。
- **写作**：自定义题目、计时、字数统计、本地历史与可选 AI 反馈；不内置私人模板或课程讲义。
- **口语**：自定义话题、浏览器本地录音、回听、文字稿记录与可选 AI 文本反馈；录音不会自动上传。
- **数据**：记录默认保存在当前浏览器，可导出/导入 JSON 备份。
- **AI**：基础功能完全离线；高级反馈支持使用者自己的 OpenAI 兼容 API 或本地模型。

## AI 配置

进入“AI 与数据设置”，填写接口地址、API Key 和模型名。连接测试成功后，AI 按钮才会启用。

- Key 只保存在启动器的进程内存中，退出后自动清除。
- Key 不写入本地存储、备份文件或仓库。
- 本地模型需要使用者自行安装和启动，本项目只保留兼容接口。
- 连接测试会发送一条极短请求，云端 API 可能收取极少量费用。

详见 [AI 配置说明](docs/AI_CONFIGURATION.md)。

## 学习材料从哪里来

可以使用自己创作/录制的材料、官方公开样题、明确采用开放许可的材料，以及自己合法取得并只在个人范围内使用的材料。本项目不提供具体商业题库下载地址，也不鼓励绕过付费或传播限制。

导入格式见便携版中的“使用指南”，也可查看 [材料导入格式](docs/import-format.html) 和 [版权边界](docs/CONTENT_GUIDE.md)。`examples` 中只有项目原创的结构示例。

## 隐私说明

学习记录保存在浏览器的本地存储中。清除浏览器数据、换浏览器或换电脑前，请先在设置页导出备份。录音默认只在当前页面会话中保留，需要长期保存时请主动下载。

当你主动使用 AI 反馈时，作文或口语文字稿会发送给你配置的服务商；听阅材料和音频不会被项目自动发送。请自行阅读相关服务商的隐私政策。

## 开发与构建

前端位于 `app/`，使用原生 HTML/CSS/JavaScript，无 npm 运行时依赖。`launcher/` 是仅使用 Go 标准库的本地启动器和 AI 代理。

开发者需要 Go 1.22+：

```powershell
go run ./launcher
```

构建 Windows 便携包：

```powershell
./build-portable.ps1 -Version dev
```

推送 `v*` 标签后，GitHub Actions 会自动生成 Release ZIP。普通使用者无需这些开发依赖。
